# مِشْكاة

مساعد ذكاء اصطناعي يجيب عن الأسئلة الشرعية وحدها، ويقابل كل دليل بمصدره قبل عرضه:
الآيات تُجلب من المصحف بالرسم العثماني، والأحاديث تُخرَّج من موسوعة الدرر السنية مع حكم المحدّث.

---

## النشر في ثلاث خطوات

### ١) ارفع المجلّد إلى GitHub

أنشئ مستودعًا جديدًا (Public) وارفع محتويات هذا المجلّد كما هي.
الملفات في جذر المستودع **مبنيّة مسبقًا**، فلا تحتاج إلى تثبيت أي شيء على جهازك.

### ٢) فعّل GitHub Pages

في المستودع: **Settings → Pages**

- Source: `Deploy from a branch`
- Branch: `main` والمجلّد: `/ (root)`
- احفظ، وانتظر دقيقة

يصير الموقع على: `https://اسمك.github.io/اسم-المستودع/`

### ٣) انشر الوركر وضع عنوانه

التطبيق لا يحمل أي مفتاح. المفتاح يبقى على وركر كلاودفلير.

1. احصل على مفتاح مجاني من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — بلا بطاقة بنكية.
2. ادخل [cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Worker.
3. الصق محتوى `worker.js` مكان الكود الافتراضي، ثم Deploy.
4. في **Settings → Variables**:
   - أضف **Secret** باسم `GEMINI_KEY` وقيمته المفتاح.
   - أضف **Variable** باسم `ALLOWED_ORIGIN` وقيمته عنوان موقعك، مثل `https://اسمك.github.io`.
5. انسخ عنوان الوركر، ثم افتح **`config.js`** على GitHub واضغط ✏️ وضعه:

```js
window.MISHKAT = {
  proxy: "https://mishkat.اسمك.workers.dev",
  hadithProxy: "",
};
```

احفظ. بعد ثوانٍ يعمل التطبيق للجميع بلا حساب ولا مفتاح، وبلا أي تكلفة عليك.

> إن تركت `proxy` فارغًا فلن يعمل التطبيق على الإنترنت، لأنه لن يجد جهةً يسأل.

## تخريج الأحاديث

موقع الدرر السنية يمنع الطلبات المباشرة من المتصفح (CORS)، فتظهر عبارة «تعذّر التحقق» على الأحاديث.
الآيات تُتحقّق دائمًا لأن `api.alquran.cloud` يسمح بذلك.

لتفعيل تخريج الأحاديث: انشر وركرًا وسيطًا يمرّر الطلب، ثم ضع عنوانه في `hadithProxy`.

## التعديل على التطبيق

هذا المستودع يحوي **الناتج المبنيّ فقط** (`app.js` مصغّر)، وليس مصدره الأصلي —
فلا يوجد فيه `src/App.jsx` ولا `package.json` يسمحان بإعادة البناء من هنا.
لتعديل التطبيق: عدّل المصدر الأصلي في مشروعه، ثم أعد البناء وارفع ناتج البناء
(`index.html`, `app.js`, `sw.js`, وغيرها) إلى جذر هذا المستودع مكان الملفات الحالية.

استثناء واحد: **`config.js`** يمكن تعديله مباشرة على GitHub (زر ✏️) دون إعادة بناء،
كما في الخطوة ٥ أعلاه.

---

## ما بداخل المشروع

```
index.html       صفحة الدخول
app.js           التطبيق المبنيّ (React، مصغّر)
config.js        عنوان الوركر — يُعدَّل مباشرة على GitHub
sw.js            عامل الخدمة (التشغيل بلا إنترنت والتثبيت كتطبيق)
manifest.webmanifest  بيانات تثبيت التطبيق (PWA)
```

> وركر كلاودفلير (`worker.js`) الذي يحمل المفتاح **غير موجود في هذا المستودع** —
> يُدار وينشر بشكل منفصل على حساب Cloudflare (راجع الخطوة ٣).

## تنبيه

الجواب من نموذج ذكاء اصطناعي وقد يخطئ في تنزيل الدليل على المسألة.
وسم «مُطابق للمصدر» يعني أن موضع النصّ ثبت، لا أن الاستدلال به صحيح.
لا يُعتمد فتوى في النوازل الشخصية؛ تُراجَع فيها دار إفتاء معتبرة.
